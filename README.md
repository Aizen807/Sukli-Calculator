# Sukli Calculator

A simple fare + change (sukli) calculator built for sari-sari store / jeepney-style use.

## Features
- Type fares as a sum, e.g. `15+13+24`, and the total is calculated automatically
- Quick-tap payment buttons (₱10–₱1000) or type a custom amount manually
- Instant sukli (change) calculation with a peso-denomination breakdown
- Installable as an app on both PC and mobile (PWA support)
