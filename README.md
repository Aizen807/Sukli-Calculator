# Sukli Calculator

A simple fare + change (sukli) calculator built for sari-sari store / jeepney-style use.

## Features
- Type fares as a sum, e.g. `15+13+24`, and the total is calculated automatically
- Quick-tap payment buttons (₱10–₱1000) or type a custom amount manually
- Instant sukli (change) calculation with a peso-denomination breakdown
- Installable as an app on both PC and mobile (PWA support)

## Live site
Once published via GitHub Pages, this will be available at:
`https://<your-username>.github.io/sukli-calculator/`

## How to publish
1. Create a new **public** GitHub repository (e.g. `sukli-calculator`)
2. Upload `index.html` and this `README.md` to the repo
3. Go to **Settings → Pages**, set Branch to `main` / `root`, and save
4. Wait ~1 minute for the link to go live

Note: the install button and offline support only activate once hosted on `https://` (like GitHub Pages) — they won't work when the file is opened locally.
